# Assets

- **music.mp3**: background song. Put an mp3 here with exactly this name. Until you do, the music button stays hidden.
  Placeholder pick: *"Din Shagna Da"* (Phillauri). Other good options: *"Kabira"* (YJHD), *"Mehendi Laga Ke Rakhna"* (DDLJ),
  *"Ve Kamleya"* (Rocky Aur Rani), or an instrumental shehnai/sitar version.
  Keep it under about 5 MB (128 kbps is fine) so it loads quickly on mobile data.
- **preview.jpg**: optional image (1200×630) shown when the link is shared on WhatsApp.
